# 快速开始

面向开发者和评审的一键起服务指南。

## 环境要求

| 项 | 版本 | 说明 |
|---|---|---|
| Python | **3.12** | 依赖 `sqlalchemy[asyncio]==2.0.36` 的 typing 支持 |
| Node.js | **20+** | Vite 6 需要 |
| 操作系统 | Windows 10/11 · Linux · macOS | Windows 用户请确保终端为 UTF-8 |
| Qwen API Key | — | [阿里云百炼](https://bailian.console.aliyun.com/) 申请 |

## 后端

```powershell
# 1) 进入 backend 目录
cd AI_Scientist_v2\backend

# 2) 创建并激活虚拟环境
python -m venv .venv
.\.venv\Scripts\Activate.ps1        # PowerShell
# .\.venv\Scripts\activate.bat      # cmd
# source .venv/bin/activate         # Linux/Mac

# 3) 安装依赖
pip install -r requirements.txt
pip install -r requirements-dev.txt # 可选，含 pytest

# 4) 配置环境变量
copy .env.example .env              # Windows
# cp .env.example .env              # Linux/Mac
# 编辑 .env，把 QWEN_API_KEY= 后面填上真实密钥

# 5) 初始化数据库（建表 + 创建 admin 账号 + 3 个内置实验模板）
python -m app.database.init_db

# 6) 启动服务
python run.py --reload
```

访问：
- API 文档：<http://localhost:8000/docs>
- 健康检查：<http://localhost:8000/api/health>
- 默认账号：`admin / admin123456`

## 前端

```powershell
# 新开一个终端
cd AI_Scientist_v2\frontend

npm ci            # 或 npm install
npm run dev       # http://localhost:5173
```

Vite dev-server 会自动把 `/api/*` 代理到 `http://localhost:8000`（见 `vite.config.ts`）。

## Docker 部署

```bash
cd AI_Scientist_v2
# 准备 .env
cp backend/.env.example backend/.env
# 编辑 backend/.env 填入 QWEN_API_KEY

docker compose up --build
# backend → http://localhost:8000
# frontend → http://localhost:5173（构建后 serve dist）
```

## 生产模式（单端口）

```bash
# 1) 前端构建
cd frontend && npm run build   # → dist/

# 2) 后端启动，会自动挂载 frontend/dist
cd ../backend
uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 4
```

单端口 `:8000` 同时提供 API + SPA fallback。

## 数据库迁移（Alembic）

**首次使用**（已有 `zhixing.db`）：

```bash
cd backend
alembic stamp head       # 把当前 DB 标记为已应用 0001 baseline
```

**新增 ORM 字段后**：

```bash
# 1) 修改 app/database/models.py
# 2) 生成迁移
alembic revision --autogenerate -m "add_xxx_column"
# 3) 审查生成的迁移文件
# 4) 应用
alembic upgrade head
```

**全新环境**：

```bash
alembic upgrade head     # 一步建全 20+ 表
```

## 常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| `UnicodeEncodeError: 'gbk' codec ...` | Windows 终端 GBK，emoji 打印失败 | `main.py` 已内置 `sys.stdout.reconfigure('utf-8')`；alembic.ini 保持 ASCII |
| `401 Unauthorized` 一直跳登录 | JWT 过期 / SECRET_KEY 不一致 | 清 localStorage 重登；检查 `.env::SECRET_KEY` |
| 前端连不上后端 | CORS 或代理 | 确认 `ALLOWED_ORIGINS` 含 `http://localhost:5173`；检查 `vite.config.ts::server.proxy` |
| Qwen 返回 `Arrearage` | 阿里云账号欠费 | 充值 → 等待 3-5 min 同步 → 新建任务重跑（旧任务已脏） |
| 进度 100% 但文档未生成 | P0-1 已知坑 | **已修复**：`progress_sync` 运行中上限 95；5 min 后僵尸任务自动标 `failed` |
| `sns.scatterplot(x='col')` 报 KeyError | wrapper 未传 data | **已修复**：`_build_wrapper` 自动补 `data=df` |
| 任务卡在 running | Agent 长时超时 | `POST /api/v1/questions/tasks/{id}/retry`；或 `cleanup_zombies` 每小时扫 |

## 验证 Qwen 连通性

```python
# scripts/check_qwen.py（可自行创建）
import asyncio, os
from dotenv import load_dotenv; load_dotenv()
from app.agents.qwen_client import call_qwen

async def main():
    r = await call_qwen("You are a helpful assistant.", "Ping, reply Pong.")
    print("RESPONSE:", r["content"])
    print("TOKENS:", r["tokens"], "COST:", r["cost"], "元")

asyncio.run(main())
```

预期返回 Pong 或类似简短响应；若 400/401，则 API Key 有问题。
