## 摘要

**智研星枢** 面向"AI for Science"，基于**国产开源大模型 Qwen**，采用**多智能体系统（Multi-Agent）架构**，实现从"科学问题输入"到"可验证科学假设输出"的全链路智能闭环。

- **15 个专职 Agent + 中央 Orchestrator**：知识缺口识别 → 文献挖掘 → 假设生成 → 反思迭代 → 实验设计 → 代码验证 → 标准化输出
- **代码级可验证**：内置实验模拟场，沙箱执行 Python 分析代码并产出图表 / 视频
- **国产自主可控**：文本走 qwen-max、视觉走 qwen-vl-max，全链路阿里云百炼 DashScope
- **标准化输出**：12 项字段严格符合赛题《科学假设与研究计划》规范（文档模板契约承载）
- **双赛道覆盖**：内置 Science 2005 版 125 题前沿科学问题（自然科学 + 人文社科）

**核心指标**：

| 指标 | 数值 |
|---|---|
| 前端代码 | 16,577 行（Vue / TS，76 文件） |
| 后端代码 | 22,909 行（Python，115 文件） |
| REST API 端点 | 178 个操作 / 145 条路径 |
| Agent 数量 | 15 个注册 + 1 个 Orchestrator |
| 数据库表 | 33 |
| 内置科学问题 | 125 题（Science 2005） |

### 2.2 请求生命周期

1. Vue 组件 → Pinia action → `api/modules/*.ts`（Axios）
2. Vite dev-server 代理 `/api` → `http://localhost:8000`
3. FastAPI 路由 → 依赖注入（DB session + JWT 当前用户）
4. Service 层执行业务；重任务丢给 `BackgroundTasks`
5. Agent Orchestrator 调用 Qwen，产出写回 `AgentTask` / `QuestionTask`

7. 前端轮询 `/status` 或 SSE → 实时刷新进度条与文档

### 3.2 协作模式：编排器 + 专业化 Agent + 反思循环

```
                     ┌───────────────┐
                     │  Orchestrator │ (中央状态机)
                     └──┬────┬────┬──┘
               ┌────────┘    │    └───────┐
               ▼             ▼            ▼
        [知识缺口]      [假设生成]     [实验设计]
        KnowledgeGap → Hypothesis → Design → ... → Writing
               ▲                            │
               │      ┌─────────────────────┘
               │      ▼
               │   [质量门禁] ─fail─▶ [反思迭代] ─▶ 回到 Hypothesis
               │    QualityGate   ReflectionAgent
               │
               └──── 满足自洽性 / 可行性 → 输出标准化假设
```

### 3.3 反思循环伪代码

```python
# agents/orchestrator.py (简化示意)
async def run_pipeline(question: str) -> Hypothesis:
    state = await knowledge_gap(question)
    state = await literature(state)
    state = await hypothesis(state)

    for iteration in range(MAX_ITERATIONS):
        state = await design(state)
        state = await analysis(state)
        review = await quality_gate(state)

        if review.passed and review.self_consistent:
            break
        feedback = await get_human_feedback(state) or review.comments
        state = await reflection(state, feedback)

    return await writing(state)
```

### 3.4 上下文工程

- `BaseAgent.build_prompt(research_question, context, **kwargs)` 统一签名
- 上下文裁剪：所有 Agent 强制 `context[:5000]`，`prompt_guard.sanitize_for_llm()` 过滤注入
- Pydantic Schema 定义在 `app/schemas/` 与 `app/contracts/document_template.py`
- 每步 `AgentTask` 持久化 prompt / output / tokens / cost，可完整回溯

## 四、9 阶段流水线（对应赛题"科研灵感流水线"）

题库任务的生成走 `batch_pipeline`，由 **9 个阶段**组成，完整实现赛题「文献挖掘 → 假设生成 → 论证迭代 → 思辨」流程：

| # | 阶段 | 名称 | 对应赛题能力项 |
|---|---|---|---|
| 1 | knowledge_gap | 知识缺口识别 | (一) 文献挖掘 |
| 2 | literature | 文献调研与事实提取 | (一) 避免断章取义 |
| 3 | hypothesis | 假设生成（归纳+演绎） | (二) 逻辑驱动 |
| 4 | design | 实验设计 | (三) 论证可行 |
| 5 | experiment_plan | 实验编排 | (三) 多轮迭代 |
| 6 | analysis | 数据分析 | 可验证性 |
| 7 | writing | 报告撰写 | 标准化输出 |
| 8 | review | 质量评审 | 自洽性 |
| 9 | reflection | 反思迭代 | (四) 人在回路 |

**内置模式**：

| 模式 | 阶段 | 用途 |
|---|---|---|
| `builtin_default_mode` | 全部 9 阶段 | 完整科研闭环（默认） |
| `builtin_quick_analysis` | 1→2→3 | 快速分析 |
| `builtin_literature_hypothesis` | +4 | 文献 + 假设 |

每个阶段的输出作为下阶段的输入，均经 Pydantic 契约校验；任一步失败 → 异常向上传播 → `QuestionTask.status='failed'` + `error_message` **透传到前端**。

## 五、标准化输出：《科学假设与研究计划》

严格遵循赛题"四、生成结果规范"的 **12 项字段**要求。实现方式是**文档模板契约 + 导出渲染**，而非在 `Hypothesis` 表单列直存：

- 模板契约 `app/contracts/document_template.py` 的 `NH_202619_TRACK1_TEMPLATE` 定义 12 个标准化章节（下方表格即其 `section_id`）；
- 导出层 `api/v1/export.py` 聚合假设本体与证据链，经模板 `templates/challenge_cup_template.html` 渲染为标准 PDF；
- 数据侧 `Hypothesis` 表以 13 个通用列（`statement` / `variables` / `evidence_chain` / `testability_score` / `version` …）承载假设与证据链，导出时映射到规范章节。

| 规范字段 | 对应模板章节 `section_id` | 说明 |
| --- | --- | --- |
| 待研究问题（Problem Statement） | `problem_statement` | 明确指出领域局限性 |
| 解决思路（Rationale） | `rationale` | 逻辑推导链条 |
| 必要的技术手段（Technical Details） | `technical_details` | 统计 / ML / 深度学习具体技术栈 |
| 数据集（Datasets） | `datasets` | Source + Target 分离 |
| Source（历史数据依据） | `source` | 引用真实历史数据 |
| Target（拟采集数据特征） | `target` | 验证实验所需数据 |
| 标题（Paper Title） | `paper_title` | 符合学术规范 |
| 摘要（Paper Abstract） | `paper_abstract` | 背景 / 方法 / 预期结果 |
| 方法论（Methods） | `methods` | 模型架构 / 实验流程 |
| 实验设计（Experiments） | `experiments` | 基线对比 + 评估指标 |
| 实验结果（Results） | `results` | 公式推导 / 实际执行验证 |
| 参考论文（References） | `references` | **严禁虚构，真实文献列表** |

**关键约束**：`references` 全部来自 `LiteratureAgent` 真实检索，导出层 `export.py::_refs()` 会拒绝无 DOI / 年份的可疑条目。
